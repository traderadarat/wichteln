      So funktioniert’s

      • Wer wen beschenkt, steckt unleserlich verpackt im persönlichen Link. Es gibt keinen Server und keine Anmeldung.
      • Deine Eingaben bleiben nur in diesem Browser gespeichert. Am selben Gerät kannst du später weitermachen, etwa um einen Link nochmal zu schicken.
      • Öffne keine fremden Links, sonst kennst du die Überraschung. Absolut geheim wie ein Tresor ist es nicht: Wer es drauf anlegt, könnte einen Link entschlüsseln. Für die Familie reicht es.
